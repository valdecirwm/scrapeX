📚 Documentação da API

        
Endpoints disponíveis

      

    


    


      

        

          GET
          /api/scrape
        

        
Scraping básico via query string. Retorna HTML, links, imagens e meta tags.

        

          ?url=https://... &render_js=true &timeout=15000 &wait=1000 &return_page_source=false
        

      


      

        

          POST
          /api/scrape
        

        
Scraping avançado via JSON body. Suporta headers customizados, cookies e extract_rules.

        

{ "url": "...", "extract_rules": { "prices": ".price", "titles": { "selector": "h1", "type": "text" } }, "custom_headers": {}, "cookies": "..." }
        

      


      

        

          POST
          /api/bulk
        

        
Scraping em massa de até 20 URLs em paralelo. Retorna resultados com status individual.

        

{ "jobs": [ { "url": "https://a.com" }, { "url": "https://b.com", "extract_rules": {...} } ] }
        

      


      

        

          POST
          /api/extract
        

        
Extração focada de dados com seletores CSS. Ideal para scraping estruturado.

        

{ "url": "...", "selectors": { "quotes": ".quote .text", "authors": { "selector": ".author", "type": "text" } } }
